# S1.0 — Stage 1 注册表、长连与命名空间契约锁定

## 1. 价值与验收场景

完成单租户 Hub、一次性邀请、设备长连、自动重名编号、TTL 与吊销的最小可用闭环，并删除所有未兑现的占位接口。

- **启动**：`dl hub --addr 127.0.0.1:0 --state-dir <dir>` 生成自签 CA/证书与 `controller_token`（权限 0600）；`dl ls --json` 返回 `[]`。
- **邀请输出**：`dl invite --name mac [--ttl 24h]` 只输出可直接粘贴的：
  `dl join --hub <url> --code <code> --ca <caPath>`（不带 `--name`，不带 `--service`）。
- **加入与重名**：`dl join --hub <url> --code <code> --ca <path> [--state-dir <dir>]` 换取并持久化 `device_token`；第二台同名设备自动命名为 `mac-2`；同一设备用原 `state-dir` 重连复用 `mac`，不新增 `mac-3`。
- **一次性邀请**：同一 `--code` 第二次 `join` 必须失败（401）且进程非零退出。
- **断连与恢复**：经 TCP 代理断开 3s 后 `dl ls` 状态为 `missed`，恢复后自动重连为 `alive` 且保留原名。
- **TTL 与吊销 Fail-Closed**：`dl ttl mac 2s` 到期或 `dl rm mac` 后，Hub 断开该节点并将其标记 `missed`/移除；节点收到 401/403 后必须**非零退出**，不得无限退避重连。
- **优雅退出**：Hub 与 Node 收到 SIGTERM 后在 5s 内退出（退出码 0），无残留子进程或临时文件。

## 2. 范围内 / 范围外（禁止项）

- **范围内**：`hub` / `invite` / `join` / `ls` / `ttl` / `rm` 6 个子命令及对应 HTTP/WS 路由。
- **禁止项**：
  - `dl join` 禁止注册 `--name` 和 `--service`（Stage 4 才实现 `--service`，当前不得保留无效 flag）。
  - 禁止实现 `exec` / `job` / `cp` / `transfer` 的任何路由、消息类型或占位字段。
  - 禁止为 Stage 2/3 预留接口、抽象层或配置字段。

## 3. CLI / Wire 增量

- CLI：`dl join` 参数收敛为 `--hub`、`--code`（首次）、`--ca`、`--state-dir`。
- HTTP（Bearer 鉴权）：
  - `POST /v1/invites`（controller）：`{name, ttl_seconds?}` → 201 `{code, name}`。
  - `POST /v1/join`（无 token，凭 code）：`{code, os, arch, shell}` → 201 `{device_token, name}`；无效/过期/已用 code → 401。
  - `GET /v1/devices`（controller）→ 200 `[{name, status, os, arch, shell, expires_at, last_seen}]`。
  - `PUT /v1/devices/{name}/ttl`（controller）：`{ttl_seconds: int|null}` → 200；不存在 → **404**；DB 内部故障 → **500**。
  - `DELETE /v1/devices/{name}`（controller）→ 204；不存在 → **404**；DB 内部故障 → **500**。
  - Controller 端点持设备 token 或错误 token → 401/403。
  - `GET /v1/node`（device token，升级 WebSocket）：无效/吊销/过期 token → **401 或 403**。
- WS：节点周期发送 `"ping"`（1s 间隔）维持 `last_seen`；Hub 超过 ~3–4s 未收到消息判定断连。

## 4. 简化与删除预算

- 新增包 ≤ 1（仅当合并 `client`/`node` 重复的 TLS CA 客户端与 `hub`/`node` 重复的 WS 心跳循环能**减少净行数**且不引入转发层时才允许）。
- 新增第三方依赖 = 0；新增接口 = 0（仅复用现有 `scanner` 或标准库接口）。
- 必删：`node.Config.Name`、`cmd/dl` 的 `join --name`、`join --service`、`invite` 输出中的 `--service`。
- 目标：相比整改前 `src_loc=1511`、二进制 `11,550,722` 字节，净代码行数不增加，单连接 goroutine 数量不增加。

## 5. 数据结构与错误建模

- `registry.ErrNotFound` 哨兵错误区分「设备不存在（404）」与「存储故障（500）」，配合 `errors.Is` 判断。
- 节点连接错误区分「永久鉴权失败（401/403 → 立即返回错误退出）」与「瞬时网络故障（有界退避重连）」。
- 用扁平 `switch` / 早返回保持主流程靠左，禁止用冗余 `else` 和布尔状态组合模拟连接状态。
